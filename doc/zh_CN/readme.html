什么是 NVDA Coach？

NVDA Coach 是一款交互式训练插件，通过简短的动手练习来教你 NVDA 命令。你不必对着手册死记硬背，而是可以实时练习每一个命令，并获得语音反馈。NVDA Coach 会一步一步地引导你，让你在 NVDA 内部按照自己的节奏稳步前进。

NVDA Coach 专为完全零基础的初学者以及刚刚开始接触屏幕阅读器的朋友而设计。它的开发者是一位每天都在与这些学员打交道的辅助技术讲师。

开始使用

按 NVDA+Shift+C 打开 NVDA Coach。屏幕上会出现一个常驻的 Coach 窗口。第一次打开时，你会看到一段介绍和一个课程选择器。用方向键选择一课，然后按 Enter 开始。

在整个学习过程中，Coach 窗口都会保持打开，这样你随时都能看到当前的指令。如果你在课程中切换到了其他窗口去练习，随时可以按 NVDA+Shift+C 回到 Coach 窗口。

课程进行中

每一课都会引导你完成一小串步骤。对于要求你尝试 NVDA 命令的步骤，请切换到其他窗口执行该操作，然后按 NVDA+Shift+C 回到 Coach 窗口，再按 Enter 确认并继续。对于带有内嵌练习文本的步骤，只需按下箭头进入 Coach 窗口内的文本区域，直接在那里练习即可。在任何课程中，以下按键始终可用：

  • Enter：前进到下一个步骤。
  • F1：重复当前指令。
  • F2：获取当前步骤的提示。再次按下可依次收听每个步骤最多三条提示。
  • F3：跳过当前步骤。
  • Escape：停止当前课程。
  • NVDA+Shift+C：从任何其他窗口返回 Coach 窗口。

在课程之间切换

完成一课之后，你不必重新打开课程选择器就能继续学习：

  • Ctrl+N：进入当前章的下一课。
  • Ctrl+B：返回上一课。
  • Ctrl+R：从头重新开始当前课程。
  • NVDA+Shift+C：打开课程选择器，跳转到任意一课或任意一章。

包含的课程

1. NVDA 入门

十三个简短的练习，涵盖每位初学者都需要的基本命令，并从一个帮助你理解 NVDA 命令工作方式的框架讲起。无需任何基础。

  1. 理解命令的类别——学习键盘命令的三大类别（Windows 命令、程序命令和屏幕阅读器命令），并了解为什么 NVDA 命令只报告信息而不会改变任何内容。
  2. 认识你的 NVDA 键——找到并使用 NVDA 修饰键（Insert 或 Caps Lock）。
  3. 读出标题栏——学习 NVDA+T，随时识别当前活动窗口。
  4. 读出时间——学习 NVDA+F12，收听当前的时间和日期。
  5. 让 NVDA 停止朗读——使用 Control 键立即停止语音。
  6. 弄清你在哪里——学习 NVDA+Tab，识别当前获得焦点的控件。包含一个可实际操作的登录表单练习。
  7. 用 Tab 在控件之间移动——用 Tab 和 Shift+Tab 在对话框和表单中导航。包含可实际操作的练习表单。
  8. 激活按钮和控件——用 Enter 和空格键激活你所停留的控件。包含可实际操作的练习控件。
  9. 读出当前行——学习 NVDA+上箭头，随时重读任意一行。包含内嵌练习文本。
  10. 用输入帮助探索按键——使用 NVDA+1，安全地了解任意按键的功能。
  11. 打开用户指南——从 NVDA 菜单中找到 NVDA 帮助系统。
  12. 了解你的键盘——实体键盘参考：Ctrl 键的几种不同位置、用 Fn+方向键充当 Home/End/Page Up/Page Down、Fn Lock，以及多媒体模式与 F 键模式的区别。
  13. 用 Alt+Tab 切换窗口——按一次 Alt+Tab 在两个窗口之间来回切换；按住 Alt 再连续轻按 Tab 可在多个窗口之间循环。

2. 认识你的键盘

三节课，在正式学习命令之前先带你熟悉实体键盘。涵盖标准键盘和笔记本键盘两种类型。

  1. 修饰键及其位置——在标准键盘和笔记本键盘上找到 Ctrl、Shift、Alt、Windows 键以及 NVDA 键（Insert 和 Caps Lock）的位置。
  2. 功能键与 Fn 键——F1 到 F12、多媒体模式与 F 键模式、用 Fn+方向键充当 Home/End/Page Up/Page Down，以及 Fn Lock。
  3. 台式与笔记本键盘布局——布局设置的含义、如何查看和更改，以及 NVDA Coach 如何在每一课中同时给出两种布局的按键。

3. 阅读和浏览文本

七节课，教你精准地浏览文档、电子邮件和文本框。每节课都在 Coach 窗口中直接内置了练习文本区域——无需切换到其他应用程序。

  1. 按字符移动——用右箭头和左箭头逐字符浏览文本。
  2. 逐词跳转——用 Control+右箭头和 Control+左箭头按词移动。
  3. 逐行移动——用下箭头和上箭头一行一行地通读文档。
  4. 跳到开头和结尾——用 Control+Home 和 Control+End 立即跳到文档的任意一端。
  5. 从这里开始读完全部——全文朗读会不间断地一直读下去。台式布局：NVDA+下箭头。笔记本布局：NVDA+A。
  6. 选择并突出显示文本——用 Shift 加方向键按字符、按词、按行选择文本；用 NVDA+Shift+上箭头（台式）或 NVDA+Shift+S（笔记本）报告所选内容；用 Control+C 复制。
  7. 按段落和页面导航——用 Control+上/下箭头按段落移动；用 Page Up/Page Down 进行更大幅度的跳转。

4. 浏览模式与网页导航

十节课，教你使用 NVDA 的浏览模式浏览网页。开始本章任意一课时，都会自动打开一个练习网页。

  1. 关于浏览模式——什么是浏览模式，以及如何切换到你的浏览器。
  2. 按标题导航——用 H 和 Shift+H 在任意页面的标题之间跳转。
  3. 跳转到指定标题级别——用数字键 1 到 6 跳转到特定级别的标题。
  4. 按链接导航——用 K 和 Shift+K 在链接之间移动；用 Tab 在可交互元素之间移动。
  5. 与表单交互——用 F、E 和 B 查找表单字段、编辑框和按钮。
  6. 焦点模式与浏览模式——用 NVDA+空格键在阅读模式和输入模式之间切换；焦点模式会把光标放进编辑框。
  7. 地标和列表——用 D 在页面地标之间跳转；用 L 在列表之间跳转。
  8. 元素列表——用 NVDA+F7 打开一个完整列表，其中包含页面上所有的标题、链接或表单字段。
  9. 在页面中查找文本——用 NVDA+Ctrl+F 在页面内搜索；用 NVDA+F3 和 NVDA+Shift+F3 在结果之间向前和向后移动。
  10. 导航表格——用 Ctrl+Alt+方向键在表格单元格之间移动；了解进入表格时 NVDA 会播报什么。

5. 对象导航

六节课，教你到达 Tab 键无法访问的控件。全程使用层级/金字塔模型——“上一层”“下一层”“同一层”——而不使用父/子术语。每一课都同时给出台式和笔记本两种布局的按键。

  1. 什么是对象导航？——金字塔模型、什么时候该使用对象导航，以及先把窗口最大化的重要性。
  2. 移动到下一个和上一个对象——NVDA+小键盘 6 和小键盘 4（台式）；NVDA+Shift+右/左箭头（笔记本）。区分 NVDA+Tab 与对象导航器。
  3. 在层级之间上下移动——NVDA+小键盘 8 和小键盘 2（台式）；NVDA+Shift+上/下箭头（笔记本）。
  4. 读出当前导航对象——NVDA+小键盘 5（台式）；NVDA+Shift+逗号（笔记本）。连按两次可逐字拼读名称。
  5. 把键盘焦点移到导航对象上——把焦点移到通过导航找到的任意对象；把导航器同步到当前焦点。
  6. 对象导航什么时候有用——三种适合使用对象导航的场景，以及练习建议。

6. 自定义 NVDA

两节课，教你调整 NVDA，让它更符合你的键盘和语音偏好。完成本章即可触发结业证书。

  1. 更改键盘布局——在 NVDA 设置中，在台式（数字小键盘）布局与笔记本（字母键）布局之间切换。
  2. 合成器设置环——无需打开对话框，即时调整语速、音调、音量和语音。还介绍 NVDA 设置中的“语音”面板，便于精确控制。

练习环境

多节课都内置了练习环境，让你不离开课程就能尝试真实的命令：

  • 可实际操作的练习表单——关于 Tab 导航、激活控件和识别焦点的课程会打开一个单独的无障碍表单窗口，里面有真实的按钮、复选框和文本框供你练习。
  • 内嵌练习文本——阅读和文本导航课程直接在 Coach 窗口中嵌入了练习文本区域。从指令处按下箭头进入文本，就能练习按字符、按词、按行移动以及选择文本，而无需切换窗口。
  • 练习网页——浏览模式课程会在你的浏览器中打开一个完全无障碍的练习 HTML 页面，包含标题、链接、表单、地标和列表。

进度跟踪

NVDA Coach 会记住你已经完成了哪些课程。已完成的课程会在课程选择器中做出标记，让你一眼就能看到自己的进度。你的进度保存在 NVDA 用户配置文件夹中，重启 NVDA 后依然保留。

写给讲师

课程以纯 JSON 文件的形式存放在插件的 lessons 文件夹中。每个 JSON 文件定义一个课程类别，其中包含按顺序排列的课程列表，而每一课又是一系列步骤。步骤可以是信息型的（学员阅读后按 Enter），也可以是手势型的（学员自己执行操作，再按 Enter 确认），还可以包含用于窗口内导航练习的内嵌练习文本。你可以通过添加新的 JSON 文件来创建新的课程类别——可以参考随附的文件作为模板。

    • 查看字体和格式（第 3 章，第 8 课）——按 NVDA+F 听取光标处的字体名称、字号、加粗、斜体和下划线信息。连按两次可打开完整的格式对话框。
    • 更改音频输出设备（第 6 章，第 3 课）——按 NVDA+Ctrl+U 打开音频输出设备选择器，把 NVDA 语音切换到耳机、外接音箱或 HDMI。
    • 控制音频闪避（第 6 章，第 4 课）——按 NVDA+Shift+D 循环切换闪避模式，让 NVDA 在朗读时自动降低其他音频的音量。
