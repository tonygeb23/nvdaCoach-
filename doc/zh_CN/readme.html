NVDA Coach 是什么？

NVDA Coach 是一个交互式训练插件，用简短练习帮助您学习 NVDA 命令。它不是让您只读说明，而是让您在真实按键练习中获得语音反馈。Coach 会一步一步引导您按自己的节奏学习。

NVDA Coach 面向刚开始接触屏幕阅读器的初学者。它由日常教授这些技能的辅助技术讲师设计，重点放在实际可用的键盘操作和稳定的练习流程上。

开始使用

按 NVDA+Shift+C 打开 NVDA Coach。屏幕上会出现一个持续存在的 NVDA Coach 窗口。首次打开时，您会看到介绍文字和课程选择器。使用光标键选择课程，按回车键开始。

NVDA Coach 窗口会在学习过程中保持可用，您随时都能回到说明。切换到其他窗口练习时，可按 NVDA+Shift+C 回到 NVDA Coach 窗口。

课程进行中

每课包含一组简短步骤。某些步骤会要求您尝试 NVDA 命令：请切换到相应窗口执行操作，然后按 NVDA+Shift+C 回到 NVDA Coach 窗口，再按 回车键 确认并继续。包含内嵌练习文本的步骤，可以直接用光标键进入 NVDA Coach 窗口内的文本区域练习。任何课程中都可使用以下按键：

  • 回车键：进入下一步。
  • F1：重复当前说明。
  • F2：获取当前步骤提示。再次按可在最多三个提示之间循环。
  • F3：跳过当前步骤。
  • Escape：停止当前课程。
  • NVDA+Shift+C：从任意其他窗口返回 NVDA Coach 窗口。

在课程之间移动

完成一课后，无需重新打开选择器即可继续：

  • Ctrl+N：移动到当前章节的下一课。
  • Ctrl+B：返回上一课。
  • Ctrl+R：从头重新开始当前课程。
  • NVDA+Shift+C：打开课程选择器，跳到任意课程或章节。

包含的课程

1. NVDA 入门

十四个短练习，介绍每位初学者都需要掌握的基础命令，并先建立理解键盘命令类别的框架。无需已有 NVDA 经验。

  1. 理解命令类别 — 学习 Windows、应用程序和屏幕阅读器三类键盘命令，以及为什么 NVDA 命令通常只是读出信息。
  2. 认识 NVDA 键 — 找到并使用 NVDA 修饰键（Insert 或 Caps Lock）。
  3. 读出标题 — 学习 NVDA+T，随时确认当前激活窗口的标题。
  4. 读出时间 — 学习 NVDA+F12，听 NVDA 读出当前时间和日期。
  5. 检查电池状态 — 使用 NVDA+Shift+B 读出电量和充电状态。
  6. 停止 NVDA 朗读 — 按 Ctrl 立即停止语音，按 Shift 暂停和继续朗读。
  7. 确认当前位置 — 学习 NVDA+Tab 读出当前焦点控件。包含无障碍练习登录表单。
  8. 用 Tab 在控件间移动 — 使用 Tab 和 Shift+Tab 浏览对话框和表单。包含交互式练习表单。
  9. 激活按钮和控件 — 使用回车键和空格键激活当前控件。包含交互式练习控件。
  10. 读出当前行 — 学习 NVDA+上光标，按需重读任意行。包含内嵌练习文本。
  11. 用输入帮助探索按键 — 使用 NVDA+1 安全了解任意按键的作用。
  12. 打开用户指南 — 从 NVDA 菜单进入 NVDA 帮助系统。
  13. 了解您的键盘 — 实体键盘参考：Ctrl 位置差异、Fn+光标键对应 Home/End/Page Up/Page Down、Fn Lock，以及多媒体模式与 F 键模式。
  14. 用 Alt+Tab 切换窗口 — 单次 Alt+Tab 在两个窗口之间切换；按住 Alt 并反复按 Tab 在多个窗口中循环。

2. 您的键盘

三课帮助您在学习命令前熟悉实体键盘，涵盖标准键盘和笔记本键盘的常见差异。

  1. 修饰键及其位置 — 找到 Ctrl、Shift、Alt、Windows 键和 NVDA 键（Insert、Caps Lock）。
  2. 功能键和 Fn 键 — 了解 F1 到 F12、多媒体模式与 F 键模式、Fn+光标键，以及 Fn Lock。
  3. 台式机与笔记本键盘布局 — 理解 NVDA 键盘布局的含义，学习如何查看和更改设置，以及课程如何同时说明两种布局。

3. 阅读和浏览文本

八课帮助您在文档、邮件和编辑框中精确移动。每课都在 NVDA Coach 窗口中提供内嵌练习文本区域，不需要切换到其他应用。

  1. 按字符移动 — 用左右光标逐字符浏览文本。
  2. 按词跳转 — 用 Ctrl+右光标和 Ctrl+左光标按词移动。
  3. 按行移动 — 用上下光标逐行阅读文档。
  4. 跳到开头和结尾 — 用 Ctrl+Home 和 Ctrl+End 立即跳到两端。
  5. 从当前位置全文朗读 — 全文朗读会连续读到文档结尾。台式机：NVDA+下光标；笔记本：NVDA+A。
  6. 选择和高亮文本 — 用 Shift+光标键按字符、词和行选择；用 NVDA+Shift+上光标（台式机）或 NVDA+Shift+S（笔记本）读出选择；用 Ctrl+C 复制。
  7. 按段落和页面导航 — 用 Ctrl+上/下光标按段落移动，用 Page Up/Page Down 做更大幅度移动。
  8. 检查字体和格式 — 用 NVDA+F 读出光标处的字体、字号和格式属性。

4. 浏览模式和网页导航

十课介绍如何使用 NVDA 的浏览模式浏览网页。开始本章任意课程时，练习网页会自动在浏览器中打开。

  1. 关于浏览模式 — 理解浏览模式是什么，以及如何切换到浏览器。
  2. 按标题导航 — 用 H 和 Shift+H 在页面标题之间移动。
  3. 跳到指定级别的标题 — 用数字键 1 到 6 跳到特定标题级别。
  4. 按链接导航 — 用 K 和 Shift+K 在链接之间移动，用 Tab 移到交互元素。
  5. 与表单交互 — 用 F、E、B 查找表单控件、编辑框和按钮。
  6. 焦点模式与浏览模式 — 用 NVDA+空格在阅读和输入模式之间切换；焦点模式会把光标放入编辑框。
  7. 路标和列表 — 用 D 在页面路标之间移动，用 L 在列表之间移动。
  8. 元素列表 — 用 NVDA+F7 打开标题、链接、表单或路标的完整列表。
  9. 在页面中查找文本 — 用 NVDA+Ctrl+F 搜索页面，用 NVDA+F3 和 NVDA+Shift+F3 在结果间前后移动。
  10. 导航表格 — 用 Ctrl+Alt+光标键在表格单元格之间移动，并了解 NVDA 进入表格时会读出什么。

5. 对象导航

六课帮助您到达 Tab 无法到达的控件。课程使用层级/金字塔模型来说明“上一层”、“下一层”和“同一层”，并同时列出台式机和笔记本布局下的命令。

  1. 什么是对象导航？ — 了解金字塔模型、何时使用对象导航，以及先最大化窗口的重要性。
  2. 移到下一个和上一个对象 — 台式机：NVDA+数字键盘 6/4；笔记本：NVDA+Shift+右/左光标。区分 NVDA+Tab 和导航对象。
  3. 向上和向下移动层级 — 台式机：NVDA+数字键盘 8/2；笔记本：NVDA+Shift+上/下光标。
  4. 读出当前导航对象 — 台式机：NVDA+数字键盘 5；笔记本：NVDA+Shift+逗号。快速按两次可拼读名称。
  5. 将键盘焦点移到导航对象 — 把焦点移到通过对象导航找到的控件，并让导航对象跟随当前焦点。
  6. 对象导航何时有帮助 — 三种适合使用对象导航的场景，以及练习建议。

6. 自定义 NVDA

四课帮助您根据自己的键盘、语音和音频环境调整 NVDA。完成本章后会触发结业证书。

  1. 更改键盘布局 — 在 NVDA 设置中切换台式机（数字键盘）和笔记本（字母键）布局。
  2. 循环切换语音设置 — 无需打开对话框即可调整速度、音调、音量和语音；也会介绍 NVDA 设置中的语音面板。
  3. 更改音频输出设备 — 选择 NVDA 语音使用的耳机、扬声器或 HDMI 音频设备。
  4. 控制音频闪避 — 调整 NVDA 朗读时是否降低其他音频音量。

练习环境

多节课程包含内置练习环境，便于您在不离开课程的情况下练习真实命令：

  • 交互式练习表单 — Tab 导航、激活控件和确认焦点的课程会打开单独的无障碍表单窗口，包含真实按钮、复选框和编辑框。
  • 内嵌练习文本 — 文本阅读和导航课程会在 NVDA Coach 窗口内嵌练习文本区域。可从说明处按光标键进入文本，练习字符、词、行和选择导航。
  • 练习网页 — 浏览模式课程会在浏览器中打开一个完全支持无障碍的练习 HTML 页面，包含标题、链接、表单、路标和列表。

进度跟踪

NVDA Coach 会记住已完成的课程。课程选择器会标记完成状态，方便查看进度。进度保存在 NVDA 用户配置文件夹中，重启 NVDA 后仍会保留。

给讲师的说明

课程以普通 JSON 文件存放在插件的 lessons 文件夹中。每个 JSON 文件定义一个章节和课程列表，每课由多个步骤组成。步骤可以是信息步骤（学生阅读后按回车键）、手势步骤（学生执行操作后确认），也可包含窗口内导航练习的内嵌文本。可参考现有文件添加新的课程章节。
