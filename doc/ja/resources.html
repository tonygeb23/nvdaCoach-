NVDAコーチ — 追加のトレーニングとヘルプ

以下のリソースを利用して、NVDA の学習を続けましょう。

NVDAコーチ リソース

  • NVDAコーチ ユーザーガイド — すべてのキーボードショートカット、レッスンの説明、カスタマイズオプションを含む、NVDAコーチ アドオンの完全なドキュメント。
  • NVDAコーチ 練習ページ — ブラウズモードのレッスンで使用されるウェブページです。見出しの移動、リンク、フォーム、表、リストの練習のためにいつでも開くことができます。
  • NVDA Coach on GitHub — ソースコード、不具合の報告、リリースのダウンロード、バージョン履歴。

公式 NVDA リソース

  • NVDA日本語チーム (nvdajp) — 日本語版NVDAのリリースや情報を提供しているコミュニティサイトです。
  • NV Access — NVDA を作成・保守している組織。最新版のダウンロード、サポートの取得、NVDA を無料で維持するための寄付ができます（英語）。
  • NVDA ユーザーガイド (オンライン) — NVDA日本語版のすべての機能とコマンドを網羅した完全なリファレンス。

ウェブアクセシビリティとスクリーンリーダーのリソース

  • WebAIM — スクリーンリーダーのテクニックやキーボードナビゲーションを含む、ウェブアクセシビリティに関する実践的なガイドや記事（英語）。
  • WebAIM: Using NVDA to Evaluate Web Accessibility — NVDA を使用したウェブナビゲーションとアクセシビリティ評価のための実践的なガイド（英語）。
  • W3C Web Accessibility Initiative (WAI) — アクセシブルなウェブデザインのための国際基準とガイドライン。
